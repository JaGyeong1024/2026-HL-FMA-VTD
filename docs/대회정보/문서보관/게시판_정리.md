## 핵심 스펙 (news/22 — 주행 경로·객체 데이터)

**주행 경로 (CSV, 대회 당일 제공)**
- VTD 월드 직교좌표계(m), egoX/egoY와 동일 좌표계 — 변환 불필요
- 첫 지점=시작점, 마지막=종료점. 중간 지점은 **2개씩 짝** = 각 교차로의 진입·진출 (seq 2·3 = 1번 교차로, 4·5 = 2번 교차로 …)
- 짝 사이 구간 = 교차로 내부. 경로는 최단거리 기준. seq 순서대로 통과해야 하며 **이탈 시 감점**
- 형식 예시: `route_example.csv` (로컬 루트에 저장됨)

**객체(objects) 데이터**
- objects[].x/y/z는 VTD 월드 좌표계(m), Ego 좌표와 동일
- 배열은 **항상 30개 고정**, `id == 0`인 슬롯은 무효(전부 0)
- Ego 제외, 수평거리(x-y 평면) **80m 이내** 객체를 가까운 순 정렬, 최대 30개. 초과분은 잘림
