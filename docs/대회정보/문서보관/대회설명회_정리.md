# 대회설명회 슬라이드 정리 (HL FMA 2026)

출처: `대회설명회 슬라이드/` 스크린샷 8장 (설명회 녹화 캡처, 2026-08-22 정리)

---

## 1. 대회 개요

| 구분 | 내용 |
|---|---|
| 대회명 | HL FMA 2026 자율주행 시뮬레이션 대회 |
| 목적 | 실제 도로 기반 가상환경에서 자율주행 제어 알고리즘을 개발·검증하고, 도로교통법 준수 능력을 정량 평가 |
| 참가 대상 | 전국 대학생 |
| 시뮬레이터 | VTD 2025.2 (Ubuntu Linux 24.04) |
| 평가 방식 | 참가자 제어기 PC ↔ 대회장 VTD PC를 Ethernet으로 연결하여 실시간 주행 평가 |
| 평가 내용 | 도로교통법 기반 평가 항목(제한속도·신호·차로유지 등) 및 동적 이벤트 대응 |
| 교육 | 2026. 8. 13.(목) 온라인 교육 1일 |

## 2. 대회 운영 방식

참가자는 제어기를 지참하고, 주최 측이 준비한 평가용 VTD PC에 연결하여 평가를 진행.

1. **참가자 준비**: 자율주행 제어기 SW, 제어기 PC/워크스테이션 지참, 인터페이스 API 연동 완료
2. **주최 측 준비**: VTD 설치 평가용 PC 제공, 맵·시나리오·평가 로직 제공, 네트워크 및 평가 환경 구축
3. **현장 연동**: 제어기 PC ↔ VTD PC Ethernet 연결, 포트/통신 규격에 따라 접속, 사전 연동 테스트 수행
4. **평가 및 채점**: 지정 시나리오 주행(약 5분), 주행 로그 기반 자동 채점, 항목별 감점·실격 판정

**평가 진행 흐름**: ① 접수 및 라이선스 발급 → ② 온라인 교육(1일) → ③ 제어기 개발 및 자체 검증 → ④ 대회 당일 현장 연동 → ⑤ 시나리오 주행 평가 → ⑥ 채점 및 결과 발표

- 평가 항목 및 평가 기준은 설명회에서 배포, 세부 배점 기준은 대회 당일 최종 제공
- 대회장 VTD PC와 참가자 제어기 간 연결 방법은 8/13 온라인 교육에서 상세 설명

## 3. 시뮬레이션 환경

| 구분 | 내용 |
|---|---|
| 시뮬레이터 | VTD 2025.2 (FULLSTACK / SIMULATE / CREATE / Perception AddOn) |
| 운영체제 | Ubuntu Linux 24.04 |
| 빌드 환경 | **GCC / G++ 8 버전 설치 필요** |
| 도로 표준 | OpenDRIVE 기반 실제 도로 데이터 |
| 시나리오 | VTD 시나리오(.xml) — 이벤트 트리거 기반 |
| 데이터 연동 | 제공 VTD 셋업 ↔ 참가자 제어기 간 TCP/UDP 통신 |
| 라이선스 | 참가자별 개별 발급 (PC MAC 주소 기준) |

## 4. 맵(Map) 구성

실제 도로 기반 **LivingLAB 맵** 사용. 평가 구역은 대회 당일 지정.

| 구분 | 내용 |
|---|---|
| 기본 제공 맵 | 화성 리빙랩 맵 (실제 도로 기반 OpenDRIVE) |
| 평가 구역 | 화성시청(남양) 구역 |
| 도로 구성 | 도심지 |
| 포함 요소 | 신호교차로 · 횡단보도 · 어린이보호구역 · 중앙선 · 실선/점선 차선 · 터널 |
| 평가 경로 길이 | 3 km 이내 |

**화성시청(남양) 구역 도로 특성**
- 도심 간선 + 다차로 구간 · 터널 포함
- 제한속도·차로유지·실선 차로변경 측정에 유리
- 후보 경로 2안 (도심 종합형 / 간선·터널형)

※ 최종 평가 맵·경로는 대회 당일 공개, 교육 시에는 동일 맵의 연습용 경로 제공
※ 참가자는 제공 맵을 그대로 사용, 필요 시 도로 수정·생성 방법은 교육 1일차에 안내

## 5. 센서 스펙

Ego 차량에 LiDAR 1개 + 카메라 1개 부착 제공.
※ 센서 설정 파일은 대회 제공 패키지에 포함, **임의 변경 불가**
※ 좌표 원점은 차량 뒷바퀴 축 중심(지면)

### LiDAR — Velodyne HDL-32E

| 항목 | 사양 |
|---|---|
| 모델 | Velodyne HDL-32E (32채널) |
| targetWidth / targetHeight | 1086 / 32 |
| 시야각 (FOV) | 수평 360° / 수직 41.4° (+10.7°, -30.7°) |
| 인지 거리 | 80 m |
| 장착 위치 (offset XYZ) | 1.0 / 0 / 2.4 |
| 장착 자세 (offset HPR) | 0 / 0 / 0 |

### 카메라 (차량 부착)

| 항목 | 사양 |
|---|---|
| 장착 위치 (position XYZ) | 1.5 / 0 / 1.6 |
| 장착 자세 (offset HPR) | 0 / 0 / 0 |
| FOV X / FOV Y | 80° / 50.6° |
| 영상 전송 | RTSP (포트 8554) |

| 구분 | 값 |
|---|---|
| 전장 (X) | 4.848 m |
| 전폭 (Y) | 1.886 m |
| 전고 (Z) | 1.507 m |
| Wheelbase | 2.944 m |
| DistFront | 3.808 m |
| DistRear | 1.04 m |
| DistLeft, Right | 0.943 m |
| TurningCircle (지름) | 12.53 m |
| MaxSteering | **0.48 rad** |

※ 좌표 원점은 차량 뒷바퀴 축 중심(지면)
※ 인터페이스 API는 라이선스 및 설치파일 배포 시 같이 제공

**제어 입력 규격**
- 조향각 (steering): rad
- 종방향 가속도 (targetAccel): m/s²
- 방향지시등 (turnSignal): 0=끔 / 1=좌회전 / 2=우회전

## 7. 연동 구성 및 통신 규격

참가자 제어기 PC와 대회장 VTD Host PC를 Ethernet 직접 연결.

- **참가자 제어기 PC**: 자율주행 알고리즘 실행, 센서/차량 데이터 수신, 제어 명령 송신
- **Ethernet 연결**: 대회장 내 직접 연결, 지정 IP/포트 사용, 사전 연동 테스트 수행
- **VTD Host PC**: 시뮬레이션 실행, 평가 셋업 구동, 주행 로그 기록·채점

| 포트 | 프로토콜 | 방향 | 용도 |
|---|---|---|---|
| 9910 | TCP | 학생 PC ↔ Host | 제어기 ↔ VTD 데이터 연동 |
| 8554 | RTSP | 학생 PC → Host 접속 | 카메라 영상 스트리밍 수신 |
| 9912 | UDP | Host → 학생 PC 접속 | 시뮬레이션 상태 전송 (LiDAR) |

(패킷 상세는 `통신_인터페이스_정리.md` 참조)

## 8. 평가 항목 — 도로교통법 기반 (법규 10개 + 동적 이벤트)

| 코드 | 평가 항목 |
|---|---|
| S1.1.01 | 제한속도 준수 |
| S1.1.02 | 보호구역(스쿨존) 속도 준수 |
| S2.1.01 | 차로 유지 |
| S2.1.02 | 중앙선 침범 · 우측통행 |
| S2.1.03 | 보도 침범 금지 |
| S2.2.05 | 실선 차로변경 금지 |
| S5.1.01 | 적색신호 정지 |
| S5.1.03 | 녹색신호 통과 |
| S6.1.01 | 도로 파손 · 장애물 대응 |
| S6.3.03 | 횡단보도 정차 금지 |

**동적 이벤트 대응 항목**
- **보행자 출현**: 거리 · 감속 · TTC · 정지 여부
- **차량 출현 / 급정거**: 안전거리 확보 및 대응
- **장애물 출현**: 감속 · 정지 · 회피
- **방향지시등**: 회전·차로변경 n초 전 점등
- **충돌**: 발생 시 점수 삭감

※ 이벤트 미발생 항목(차로유지·중앙선·보도·실선·우측통행)은 주행 로그로 상시 측정
