## 채널 요약

| 채널 | 프로토콜 | 포트 | 방향 | 내용 |
|---|---|---|---|---|
| 상태/제어 | TCP | 9910 | 양방향 | 차량 상태 수신 + 제어 송신 (단일 연결) |

모든 바이너리 필드는 **little-endian, 헤더/패딩 없음**.

## TCP 9910 — 수신 (DataPacket, 1109 bytes 고정)

> 근거: libHLVTD.so sendDataPacket 디스어셈블. 시작 로그의
> `TCP 9910 unified: DataPacket %zuB / CtrlPacket %zuB` 라인으로 1109/9 검증 가능.

| offset | 크기 | 필드 | 형식 |
|---|---|---|---|
| 0 | 24 | egoX, egoY, egoZ, egoHeading, egoPitch, egoRoll | 6 × float32 (m, rad) |
| 24 | 1080 | objects[30] — 슬롯당 36B | 아래 참조 |
| 1104 | 4 | trafficLightId | int32 |
| 1108 | 1 | trafficLightState | uint8 |

객체 슬롯 (36B): `id(uint32), x, y, z, heading, speed, length, width, height` (8 × float32)
- 항상 30슬롯 전송, `id == 0` 무효(전부 0)
- Ego 제외, 수평거리 80m 이내를 가까운 순 정렬 (news/22)
- 신호등은 **경로 기준으로 선택된 1개만** 전송 (state: 0미할당 1적 2황 3녹 4좌회전 5녹+좌 6점멸)

파이썬 언팩:
```python
import struct
FMT = '<6f' + 'I8f'*30 + 'iB'   # calcsize = 1109
def parse(buf):
    v = struct.unpack(FMT, buf)
    ego = v[0:6]
    objs = [v[6+9*i : 6+9*(i+1)] for i in range(30) if v[6+9*i] != 0]
    tl_id, tl_state = v[-2], v[-1]
    return ego, objs, tl_id, tl_state
```
TCP는 스트림이므로 정확히 1109B 단위로 재조립해서 파싱할 것.

## TCP 9910 — 송신 (CtrlPacket, 9 bytes)

`struct '<ffB'` = steering(f32, rad) + targetAccel(f32, m/s²) + turnSignal(u8: 0끔/1좌/2우)
- 예제 기준 20Hz 전송, 조향 ±0.35rad, 가속 +3.0 / -6.0 m/s²
- 예제에서 `steer_out = -steer` 부호 반전 사용 (D키=우조향이 +) — 실차 좌표 규약 확인 필요
- NaN/Inf 패킷은 플러그인이 무시함 (`non-finite CONTROL packet ignored`)
- 연결 끊기면 시뮬 쪽에서 steering=0, accel=0 처리

## UDP 9912 — LiDAR

패킷 = 42B 헤더 + N × 12B 포인트(float32 x,y,z), 기본 512pts/pkt, 20fps
헤더 `'<IHIQdHHIIHBB'`:
`magic('IVHL'=0x4C485649), version(=1), frame_id, timestamp_ns, sim_time_sec,
packet_index, packet_count, point_count_total, point_start_index,
point_count_in_pkt, coordinate_mode(1=world), point_stride_bytes(=12)`
- **월드 좌표계**로 전송됨 → base_link 기준이 필요하면 ego pose로 역변환 (시뮬 PC `docs/08-ros2-sensor-bridge.md` 참조)
- (0,0,0) 포인트는 무효 → 필터링

## RTSP 8554 — 카메라

```bash
ffplay -rtsp_transport tcp -fflags nobuffer -flags low_delay rtsp://<VTD_PC_IP>:8554/front
```
- TCP 인터리브드 전용 (UDP 전송 비활성)
- `/broadcast`는 자동기동 목록에 없어 기본적으로 스트림 없음 (수동 실행 필요)
- 1920×1080, 20fps, h264_nvenc, 4Mbps, zerolatency

- 오프로드 0.3초 지속 → 리스폰 / 경로이탈 0.5초 지속 → 리스폰
- 포즈 허용오차 1.5m, 리스폰 유예 1.0초

## 검증 방법

시뮬 PC에서 VTD 기동 후 로그에서 `TCP 9910 unified: DataPacket 1109B / CtrlPacket 9B` 확인.
또는 9910 접속해 수신 바이트가 1109의 배수인지 확인.
