## 2. 오늘 알게 된 사실 / 판단 기록

- **원칙 (사용자 지시)**: 채점 세계 = 대회장 VTD가 읽는 xodr 원본. 우리 내부 표현은 그것과의 괴리를 항상 정량 측정. **xodr 자체의 결함은 고치는 대상이 아니라 회피·검증 대상** (대회장 환경은 수정 불가)
- **route CSV의 진입 지점은 특정 차선 위에 정확히 찍혀 있음** (오차 0.1~0.3m, 좌회전 앞은 1차선) → CSV가 진입 차선을 사실상 지정. 최근접 스냅으로 회전 차선 선택 자동 해결
- **터널·스쿨존은 맵 데이터에 없음**: xodr `<tunnel>` 0건(osgb 시각 요소만), 학교 건물 object 1개뿐(road 190, (528,-86)). 스쿨존은 네이버 위성 수동 태깅 + #4939 질의로
- **터널에서 위치 끊길 걱정 없음**: GPS가 아니라 TCP GT pose(20Hz)라 구조적으로 무관. 카메라 조도만 이슈(디버깅용이면 무관)
- **실선/점선/중앙선 완비**: solid 1,752 / broken 1,111 / 겹실선 12, yellow 1,730(중앙선)·백색 1,270, **laneChange 속성(both 1,236/none 1,764)** → 실선 차로변경 판정은 이 플래그 하나로 가능
- **남은 인지 과제는 2개뿐**: ①objects에 클래스 없음(크기·속도 휴리스틱 분류 필요 — 보행자≈0.5×0.5, 차량≈4×2) ②도로파손·장애물의 objects 포함 여부(실기 확인, LiDAR 도입 여부 결정). 카메라 lane 인지는 제어에 쓰지 않기로(GT pose+맵이 완벽, 노이즈만 추가됨)
- lanelet2 라우팅은 '점 id 공유'로 연결 판정 → 익스포터에 xodr link 레코드 기반 끝점 용접 필수 (기하 근접만으론 부족)
