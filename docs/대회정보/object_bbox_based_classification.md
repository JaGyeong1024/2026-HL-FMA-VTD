# 객체 크기(bbox) 기반 분류표 — VTD objects 필드 실측 (2026-09-12)

VTD TCP 9910 `objects[]` 의 `length/width/height` 를 그대로 로깅한 값(단위 m). 브리지가 객체를 Autoware 분류(PEDESTRIAN/MOTORCYCLE/CAR …)로 바꿀 때 쓰는 근거.
측정: 시나리오에 배치 후 45~90초 로깅(`/tmp/objlog.py`). 정지·제자리 걷기 모두 전 구간 min=max 로 **크기 변동 없음**(애니메이션과 무관). 차량·오토바이·걷는 사람은 9/11 주행 bag(`test/0911_*`) raw 패킷에서.

## 2. 분류 규칙 (권장)

판정 순서대로 적용. 경계값은 실측 사이 빈 구간의 중간.

| 순서 | 분류 | 조건 | 대응 객체 |
|---|---|---|---|
| 1 | 정적 장애물 (UNKNOWN) | **H < 0.6** | 라바콘(0.32) |
| 2 | 차량 (CAR) | **L ≥ 3.5** | 승용차 4.4 |
| 3 | 이륜 (MOTORCYCLE/BICYCLE) | **1.5 ≤ L ≤ 2.8** | 자전거(탑승/빈) 1.9, 오토바이 2.0 |
| 4 | 보행자 (PEDESTRIAN) | **L ≤ 1.3 · W ≤ 0.8 · H ≥ 1.2** | 어린이~성인 0.5~0.6 길이, 휠체어 탑승자 1.01 |
| 5 | 그 외 (UNKNOWN) | 위에 안 걸리는 것 | 빈 휠체어(H 0.92) 등 |

- 탑승자 유무는 **H** 로 갈린다(빈 자전거 1.10 / 탑승 1.80, 빈 휠체어 0.92 / 탑승 1.80). 빈 자전거는 규칙 3 에서 이륜으로 잡히는데 정지물이므로 회피 대상으로 무방.
- 휠체어 탑승자는 보행자로 취급(채점 10번 보행자 대응).
- 현재 브리지 규칙(`L<1.2 and W<1.2 → PEDESTRIAN, L<2.8 → MOTORCYCLE, else CAR`)은 **라바콘을 보행자로** 분류한다 → 규칙 1(H<0.6) 을 앞에 넣어야 한다. 그 외 실측 객체는 현재 규칙으로도 같은 결과.
