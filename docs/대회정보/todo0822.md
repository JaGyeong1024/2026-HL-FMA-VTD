## 3. 오늘 알게 된 사실 / 판단 기록

- **맵 실측** (LivingLab.xodr): 651 roads/94 junctions, driving 차선 92km, 맵 1.7×2.4km. spiral 1246개(수치적분으로 처리). roadMark solid/broken 완비 → 실선 판단 맵에서 가능. **신호등 646개 전부 dynamic signal**(정지선 s좌표 포함)
- **맵 공백 확정**: 정적 signal 0개 = 속도표지·스쿨존 없음 → 국토교통부 디폴트로. 횡단보도 object 2개뿐 → 위치 보강 필요
- route_example은 시작1 + 교차로짝(2·3, 4·5, 6·7) + 종점8 구조가 시각적으로 확인됨 (교차로마다 신호등 위치 일치)
- TCP objects = perfect sensor (id/크기/heading까지 GT 수준 — 레이더 아님). 대회 설계가 "인지는 주고 판단·제어를 평가"
- SCP 패킷: magic u16=40108, ver u16=1, sender[64], receiver[64], len i32 + XML (little-endian)
- 폐루프 오차 그래프의 0~0.5m 잔진동은 최근접 '점' 측정의 이산화 노이즈 (경로점 1m 간격) — 실제 진동 아님, 선분 투영으로 개선 예정
