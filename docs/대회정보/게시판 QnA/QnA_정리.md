## 3. 0901 — 우리 팀 (톰크루즈컨트롤, 박성재): HLFMA 대회관련 질문사항 5건 원문 — `0901_우리팀_질의5건_원문.png`

1. **정지선 위치 판정 기준** — 평가항목 7번 "범퍼 기준 정지선 2m 이내 정지"인데 GT API는 신호등 state만 주고 정지선 위치는 없음. XODR의 어떤 요소(roadMark stopLine, object, signal)로 추출해야 하는지, 평가 시스템은 어떤 데이터로 판정하는지.
2. **보호구역 구간 좌표** — 붉은 노면만 평가 대상이라 안내받음. XODR에서 붉은 노면을 식별할 요소가 있는지(object명, roadMark color, road ID+s 등), 없다면 좌표·범위를 제공받을 수 있는지. 제한속도구간 주행 속도는 몇 km/h인지.
3. **신호등 점멸 상태 구분** — state 6이 점멸인데 평가항목 9번은 적색점멸 일시정지 기준. state 6은 적색·황색 점멸을 구분하지 않는지, 구분 안 되면 적색점멸을 어떻게 식별하는지.
4. **objects[].id 프레임 간 안정성** — 배열이 거리순 정렬이라 인덱스는 매 프레임 바뀜. id는 동일 객체에 대해 유지되는지, 아니면 위치 기반 추적을 해야 하는지.
5. **egoSpeed 제공 여부** — 인터페이스에 ego 속도 필드가 없어 위치 차분으로 추정 중. GT Data에 포함되는지, 아니면 평가 시스템은 어떤 값을 기준으로 제한속도를 판정하는지.

## 4. 0902 — 위 5건에 대한 답변 (Junyoung Park) — `0902_우리팀_질의5건_답변.png`

### 우리 해석·반영 (요약)
- 정지선: xodr signal/정지선 object에서 자체 추출 (맵 v2는 정지선 object 기준) — 평가 기준 데이터는 비공개이므로 실기에서 오차 확인
- 보호구역: xodr에 없음 → osgb 붉은 노면 텍스처 폴리곤 21개 추출 → 맵 lanelet 112개 speed_limit 28 km/h(규정 30, 실속도 평가 마진 2)
- state 6: 적·황 무구분 → 무조건 정지선 일시정지 0.5s 후 통과 (브리지 상태기계)
- objects id: 유지 → id 기반 yaw rate 추정에 사용
- egoSpeed: 평가는 실속도 → 목표속도 마진 (일반 46 / 보호구역 28 km/h)
